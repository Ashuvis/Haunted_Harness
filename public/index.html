Install Python and Ollama

Install Python 3.10+ and Ollama for Windows, macOS, or Linux.

Install the Python client

From the project directory, install the only Python dependency.

Download a model

The default is lightweight; a coding model usually gives more accurate explanations.

Summon a rundown

python -m pip install ollama

Troubleshooting

When the veil gets foggy.

“ollama is not recognized”

Install Ollama, then close and reopen PowerShell so the updated PATH is loaded. Verify with ollama --version.

“Only one usage of each socket address”

Port 11434 is already occupied. Query http://127.0.0.1:11434/api/tags; an HTTP 200 response means Ollama is already running.

The output is a refusal or invents details

The 1B model is small. Try qwen2.5-coder:3b or another coding-focused model, and treat generated explanations as helpful summaries rather than proof.

Can I make the site review files directly?

Not with this static deployment. A browser cannot read arbitrary files from your computer, and Vercel cannot run your local Ollama instance. Keep the CLI local or add a separately hosted, authenticated backend.
